Import Cases from CSV
CSV Import: Upload a CSV file with case data following the required format.
  • The CSV must include the following headers: CaseID, Biobank_ID, Status, DNAT, DNAN, RNA (Other_ID is still accepted)
  • Optional header: source_other_comments (will be added as a comment with timestamp and author)
  • Existing cases will be updated, new cases will be created
  • Status accepts both formats: lowercase (from export: created, received, incomplete, unknown, library_prepped, sequenced, transferred_to_nfl, bioinfo_analysis, completed) or display format (Created, Received, Incomplete, Unknown, Library Prepped, Sequenced, Transferred to NFL, Bioinfo Analysis, Completed)
  • Biobank_ID is optional and can be left empty
  • DNAT, DNAN, and RNA values should be numbers or left empty
  • source_other_comments will automatically include timestamp and author information
